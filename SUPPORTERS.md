## 📣 How to Get Listed

- **Submit a pull request** that gets merged → automatic listing in Community Contributors
- **Report a critical bug** that gets confirmed → listed with credit in the release CHANGELOG
- **Subscribe to a Premium Support Plan** → listed in Premium Supporters (with your permission)
- **Become an Enterprise Partner** → logo placement in this file and on the website

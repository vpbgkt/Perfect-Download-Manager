Frequently asked questions

Perfect Download Manager (PDM) is a free, multi-connection download manager for Windows 10 and 11. Here are straight answers to the questions people ask most before installing it.

Is Perfect Download Manager free?

Yes. PDM is free for personal and commercial use while it's in early access, with no ads and no sign-in. A paid tier with advanced features is planned, but the current version will remain free.

Does PDM work on Windows 10?

Yes. PDM supports 64-bit Windows 10 (version 1809 or later) and Windows 11. It runs on the .NET 10 Desktop Runtime, which the installer sets up automatically if it isn't already present — nothing to install separately.

Is PDM safe to use?

PDM collects no telemetry, no analytics, and shows no ads. The installer isn't code-signed yet, so Windows SmartScreen may warn you on first install — click "More info" then "Run anyway." Every update is ECDSA-signed and SHA-256 verified before it installs.

Why does Windows SmartScreen warn about PDM on first install?

Because the installer isn't code-signed yet, Windows SmartScreen shows a "Windows protected your PC" prompt for the new, unrecognized app. Click More info → Run anyway to continue. A code-signing certificate is the permanent fix and is planned, though we don't have a firm date yet. You can also verify your download against the published SHA-256 checksum.

Does PDM support Firefox?

Not yet. The PDM browser extension supports Chrome, Edge, and Brave today. A Firefox port is planned but not currently available.

Does PDM collect any data or phone home?

No telemetry, no analytics, no ads. The app contacts our servers only for two things: license validation (only if you activate a license) and checking for updates. Both are documented in our privacy policy.

How is PDM different from Internet Download Manager (IDM)?

Same core idea (multi-connection downloads and browser integration), a different implementation. PDM is built on modern .NET 10 with a Fluent-styled WPF UI, ships an MV3 browser extension with strict safety filters, and uses ECDSA-signed auto-updates — free during early access. See the full PDM vs IDM comparison.

Is there a portable version that doesn't need installation?

Yes. A portable ZIP is available: unzip it anywhere and run PDM.exe. It's the same app as the installer, just unpacked — handy for USB sticks and testing.

Where do I report a bug or get support?

Email support@perfectdownloadmanager.com. Reports with logs attached (from %LOCALAPPDATA%\PerfectDownloadManager\logs) get fixed fastest. See the support page for more options.

Changelog

Release notes for Perfect Download Manager (PDM). PDM updates itself automatically ΓÇö existing installs are offered each new stable release from inside the app (toolbar menu ΓåÆ Check for Updates). You can also download the latest version any time.

1.3.1

2026-09-06

Latest stable

  • Smooth download popup experience with professional-grade metrics display:
  • - Smooth Transferred display with 60 FPS interpolation and adaptive precision formatting
  • - Responsive Speed display with multi-layer EMA smoothing for readable feedback
  • - Rock-solid ETA countdown using dual-speed system (separate display/calculation speeds)
  • - Professional IDM-quality user experience with no jittery updates
  • Technical improvements:
  • - Implemented 90/10 EMA for ultra-stable ETA calculations (5-second rolling window)
  • - Added 70/30 EMA for responsive Speed display
  • - Linear interpolation between progress snapshots for continuous visual advancement
  • - Adaptive precision: <10 MB shows 2 decimals, 10-99 MB shows 1 decimal, ≥100 MB shows none
  • - Proper timer disposal to prevent resource leaks

1.3.0

2026-08-23

  • Fixed the license expiry countdown - it showed the 14-day re-validation window instead of your real subscription end date.
  • Download status window: clearer statistics (Transferred, Current Speed, Time Remaining, and Connections with an active count).
  • Open-the-file-automatically and a new archive-only extract-and-open option now sit next to the progress bar.
  • More compact download window that sizes itself to its content, with the wasted space removed.
  • Added a feedback form link to the download window options.

1.2.5

2026-08-19

  • Faster downloads: parallel disk writes remove the write-path throughput ceiling.
  • Adaptive connection probing - PDM starts with fewer connections and adds more only when they actually help.
  • Quicker resume: the source link is only re-probed when it may have gone stale.
  • More accurate progress reporting, with stale status labels no longer shown.
  • Groundwork for customer details and custom key prefixes on license keys.

1.2.0

  • Rebuilt, modern interface. A faster, cleaner UI with polished light and dark themes, a collapsible sidebar, real per-file icons, and a redesigned download popup with a Download/Options layout.
  • Smarter download status. The popup now explains stalls in plain language ΓÇö no internet, waiting for the server, connection timed out, unstable network, or disk errors ΓÇö instead of a silent "stuck" state.
  • When-done actions. Optionally open the file automatically or shut down the PC after a download finishes (with a cancellable countdown).
  • Cleaner toolbar & quick access. Primary actions up top with an overflow menu, a one-click Downloads-folder button, remembered browser, and a merged Add/Bulk-add button.
  • Self-contained & lighter. The app now ships without a separate .NET runtime requirement ΓÇö nothing extra to install.
  • Numerous reliability and performance improvements throughout.

1.0.26

  • Much faster resume. Paused downloads now re-spread the remaining data across all connections when resumed, so a resumed transfer runs at full speed instead of crawling on one connection.
  • Refreshed links on resume. When a download is resumed, PDM re-resolves the source link, so expiring CDN and file-host links keep working.
  • Smarter duplicate detection. Starting a download PDM already has now recognises the same file even when the link changes each time (Google Drive, signed links), and offers to continue the existing partial download, open the finished file, or start a fresh copy.
  • Change or refresh a download's link. Right-click a download to paste a new link, or re-capture a fresh one from your browser, and continue where you left off.
  • Smaller, self-setup installer. The new installer is about 41 MB and installs the .NET 10 runtime automatically if it's missing ΓÇö no separate download.
  • Support & contact. Reach the team for help or license renewals from the toolbar menu and the support page.
  • Lower memory usage while idle, and a refreshed green installer.

1.0.18

  • Reliability and UX improvements to the download engine and browser capture.
  • Signed, verified auto-updates (ECDSA + SHA-256).
